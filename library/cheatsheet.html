Cheatsheet — Microsoft's Digital-Work Platform

Decision rules and tells.

Decision rules only.

  • When X, choose Y because Z.
  • When deciding whether GitHub Copilot is "part of" Microsoft 365 Copilot, say no — they are separately licensed products (Microsoft 365 Copilot vs. GitHub Copilot Business/Enterprise) connected only operationally via shared Entra identity and the GitHub Cloud Knowledge connector. See m365-vs-github-copilot.
  • When choosing which Copilot to point a task at: business/office artifacts (briefs, spreadsheets, meeting summaries, Excel analysis) → Microsoft 365 Copilot; code/tests/IaC/PRs → GitHub Copilot; low-code business agent → Copilot Studio; production code behind an agent → GitHub Copilot plus CI/CD controls. See m365-vs-github-copilot#Division of labor.
