Which connector pattern selection aligns with the architecture decision framework?

  • Correct. Deploy a federated MCP connector for the HR platform and a synced Copilot connector for the engineering knowledge base.

During a post-implementation review of a custom synced Copilot connector indexing third-party project documentation, security auditors discover that users are receiving AI grounded answers containing sensitive financial project details they are not authorized to view in the source system. What is the primary root cause of this failure mode?

  • Correct. The connector service failed to properly map source system entitlements into the Access Control List (ACL) attached to each ingested externalItem.
  • Microsoft 365 Copilot automatically overrides source system ACLs when semantic indexing is enabled for custom connectors.
  • The target tenant was configured using Microsoft Entra ID delegated authorization instead of application-only consent.
  • The connector ingested content into Microsoft Dataverse rather than passing it through an active Model Context Protocol (MCP) gateway.

An engineering organization is integrating GitHub software delivery workflows with Microsoft 365 Copilot and external operational tools. Which of the following technical implementation choices represent recommended integration architecture patterns?

  • Correct. Use GitHub Apps with short-lived installation tokens and fine-grained repository permissions for durable server-to-server integrations.
  • Correct. Rely on GitHub webhooks, the Checks API, and branch protection rules as the system of record for lifecycle state transitions rather than an LLM agent.
  • Correct. Deploy Model Context Protocol (MCP) servers to extend Copilot Chat with real-time access to external ITSM and observability tools.
  • Configure broad OAuth apps with global organization administrative privileges to simplify service-to-service API calls across all workflows.

A solution architect is designing a cross-cloud integration strategy for a government organization operating across Microsoft 365 GCC High and DoD environments. What deployment constraint regarding Copilot connector models must be documented in the physical architecture view?

  • Correct. Synced Copilot connectors are supported in GCC High and DoD environments, whereas federated (MCP-based) connector availability varies and must be verified per connector.
  • Federated MCP connectors are natively supported in all DoD air-gapped clouds, but synced connectors are prohibited due to Graph storage rules.
  • Neither synced nor federated connectors can be deployed in GCC High due to FedRAMP restrictions on Microsoft Graph external connections.
  • Federated connectors in GCC High require all external MCP servers to be physically hosted inside Microsoft Azure Government data centers.
