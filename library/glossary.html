GLOSSARY — Microsoft's Digital-Work Platform

Terms used across the Microsoft digital-work platform deep dive, with a one-line definition each.

Collected from the mind map, the four architecture views, the study guide, and the cheatsheet. External URLs live on RESOURCES.

Term Definition Where it shows up
ACL Access control list on a Microsoft Graph item. A synced connector must map source-system permissions onto this list or Copilot can overshare. Integration view, study guide
Agent / tool integration An agent calls a governed action or workflow (create a ticket, ask for approval, update a record). State changes stay in the system of record, not in the prompt. Mind map, logical view
API consumption The app calls a third-party API at request time for a transactional read or write. No copy of the record is kept as a second system of record. Mind map
Checks API GitHub API that posts pass/fail and evidence onto a pull request. Used for tests, security findings, and release gates. Logical view, integration risks
Conditional Access Entra policy that can block or step up a sign-in. Copilot APIs inherit it because they sit on Microsoft Graph. Mind map, Copilot APIs docs
Control plane Identity, policy, secrets, catalogs, and audit. One of the three planes in the Copilot Integration Enablement Layer. Conceptual view, study guide
Copilot (role) The user-facing intelligence layer. It is not the integration layer. Durable assets are APIs, events, identity, connectors, schemas, and policy underneath it. Mind map, all views
Copilot APIs REST endpoints under Microsoft Graph that let an app invoke Microsoft 365 Copilot. Same auth model as other Graph APIs. Block sources, mind map
Copilot connector Brings external knowledge into Microsoft 365 Copilot and Search. Two kinds: synced (indexed) and federated (live MCP). Blocks, integration view
Copilot Integration Enablement Layer The target control point: an MCP/API catalog, gateway, policy, and audit so teams do not build one-off AI connections. Conceptual view, mind map
Copilot Studio Low-code place to build task-specific business agents that call APIs, Dataverse, and approved MCP tools. Separate from GitHub Copilot. Mind map, cheatsheet
Dataverse Power Platform data store behind low-code apps and some Copilot Studio agents. Mind map
Digital-work platform The Microsoft 365 side: mail, files, chat, meetings, and business process. Microsoft Graph is its API and data plane. Conceptual view
Entra ID Microsoft's identity service for this pack. Users and apps authenticate here; GitHub can federate to the same directory. Physical view, cheatsheet
Event-driven integration A source publishes a webhook or event; a consumer reacts. Used when systems must respond to a change instead of polling. Mind map, logical view
externalItem The Graph object a synced connector writes. Study guide: it must carry content, metadata, an ACL, and semantic labels. Study guide, physical view
Federated connector Live fetch at question time through MCP. Content is not copied into Microsoft Graph. Use it when data is volatile, sensitive, large, or when a write must hit the source. Blocks, logical view
GitHub App Server-to-server GitHub integration with fine-grained permissions and short-lived installation tokens. Preferred over a broad OAuth app. Mind map, integration risks
GitHub Cloud Knowledge connector Microsoft connector that indexes selected GitHub Markdown and docs into Graph so Microsoft 365 Copilot can ground on them. Source ledger, logical view
GitHub Copilot The coding assistant (IDE, CLI, chat, coding agent). Licensed separately from Microsoft 365 Copilot. Cheatsheet, mind map
GitHub Copilot Extensions Older GitHub App model for extending Copilot. GitHub has deprecated it in favor of MCP servers. Mind map, study guide
Graph change notifications Webhooks from Microsoft Graph when a resource changes. The subscriber then reads the authorized delta. Mind map
Graph Data Connect Bulk, governed export of Microsoft 365 data into an Azure analytics store. Not the same as a Copilot connector. Mind map
Indexed knowledge connector Same idea as a synced connector: copy external content into a Graph external connection so Search and Copilot can retrieve it. Mind map, study guide
Knowledge plane Curated information made searchable (synced connectors and the Graph index). Conceptual view
MCP Model Context Protocol. A way for a host (Copilot) to call tools and read context from an external server. GitHub's primary Copilot extensibility path, and the wire for federated connectors. Blocks, all views
MCP server A process that exposes tools to Copilot. Catalog it. Split read-only tools from write tools. Conceptual view, integration risks
Microsoft 365 Copilot The work assistant over mail, files, meetings, and Graph. Not the same product as GitHub Copilot. Cheatsheet, source ledger
Microsoft Graph The permission-aware API and data plane for Microsoft 365 content and for Copilot APIs. Mind map, conceptual view
OAuth 2.0 Delegated or app authorization. Graph and GitHub both use it. Broad scopes are a risk on GitHub; prefer a GitHub App for service-to-service. Physical view
OIDC OpenID Connect. Identity layer on OAuth, used for sign-in into Entra. Physical view
PAT Personal access token. Avoid it for production integrations; it is a long-lived user secret. Study guide
Permission fidelity Source-system rights must survive the trip into Graph ACLs. If the mapping is wrong, Copilot retrieval spreads the mistake. Integration view
Power Platform connector Low-code connector used by Power Automate and Power Apps. Different surface from a Copilot connector. Mind map
Prompt injection Hostile text inside retrieved content that tries to override the model's instructions. Treat retrieved text as data; gate actions outside the model. Integration view
SAML Older SSO federation option into Entra, alternative to OIDC. Physical view
SCIM Protocol for automated joiner, mover, and leaver provisioning. Physical view, study guide
Semantic index Microsoft's index that Copilot uses for grounding. Synced connector items land where this retrieval can see them. Study guide (grounding path)
Software-delivery platform The GitHub side: repos, review, Actions, packages, release. Conceptual view
Synced connector Pulls external content on a schedule into a Graph external connection (content, metadata, ACL, semantic labels). Good for search; bad for secrets and fast-changing records. Blocks, logical view
System of record The one authoritative store for a fact. Copilot must not become a second one. Conceptual view
Transaction plane APIs and workflows that change state. Distinct from the knowledge plane. Conceptual view
Work IQ API Microsoft extensibility API called out in the study guide as part of how Copilot reasons over work context. Treat product detail as Microsoft Learn, not as invented here. Study guide, source ledger
Workload identity An app or service principal, not a person. Server-to-server calls should use this (or a GitHub App), not a shared user account. Study guide
