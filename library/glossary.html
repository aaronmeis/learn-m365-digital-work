GLOSSARY — Microsoft's Digital-Work Platform

Terms for the Microsoft digital-work platform deep dive, graded by rung and cited to the source ledger.

Rung 100 names a product or plane. Rung 200 names a mechanism. Rung 300 needs a judgment or names a failure. Essential is yes when a design review cannot skip the term. Source is a ledger row, or UNVERIFIED when no row states the claim.

Term Definition Category Rung Essential Related Where it shows up Source
ACL Access control list on a Microsoft Graph external item. A synced connector must map source-system permissions onto this list or Copilot can overshare. Logical 200 yes externalItem, Permission fidelity Integration view, study guide [S15] [S3]
Agent / tool integration An agent calls a governed action or workflow. State changes stay in the system of record, not in the prompt. Logical 200 no MCP server, System of record Mind map, logical view [S6] [S7]
API consumption The app calls a third-party API at request time for a transactional read or write. No copy of the record is kept as a second system of record. Logical 200 no System of record, Federated connector Mind map UNVERIFIED
Checks API GitHub API that posts pass/fail and evidence onto a pull request. Used for tests, security findings, and release gates. Integration & AI 200 no GitHub App Logical view, integration risks [S17]
Conditional Access Entra policy that can block or step up a sign-in. Copilot APIs inherit it when they sit on Microsoft Graph. Physical 200 no Entra ID, Copilot APIs Mind map, Copilot APIs docs [S19]
Control plane Identity, policy, secrets, catalogs, and audit. One of the three planes in this pack's Copilot Integration Enablement Layer. Conceptual 200 no Knowledge plane, Transaction plane Conceptual view, study guide UNVERIFIED
Copilot (role) The user-facing intelligence layer. It is not the integration layer. Durable assets are APIs, events, identity, connectors, schemas, and policy underneath it. Conceptual 200 no Copilot Integration Enablement Layer Mind map, all views UNVERIFIED
Copilot APIs REST endpoints under Microsoft Graph that let an app invoke Microsoft 365 Copilot. Same auth model as other Graph APIs. Platform 200 no Microsoft Graph, Microsoft 365 Copilot Block sources, mind map [S1]
Copilot connector Brings external knowledge into Microsoft 365 Copilot and Search. Two kinds: synced (indexed) and federated (live MCP). Integration & AI 100 yes Synced connector, Federated connector Blocks, integration view [S3]
Copilot Integration Enablement Layer The target control point: an MCP/API catalog, gateway, policy, and audit so teams do not build one-off AI connections. Integration & AI 300 yes MCP, Control plane Conceptual view, mind map UNVERIFIED
Copilot Studio Low-code place to build task-specific business agents that call APIs, Dataverse, and approved MCP tools. Separate from GitHub Copilot. Platform 100 no Microsoft 365 Copilot, Dataverse Mind map, cheatsheet [S22]
Dataverse Power Platform data store behind low-code apps and some Copilot Studio agents. Platform 100 no Copilot Studio, Power Platform connector Mind map [S25]
Digital-work platform The Microsoft 365 side of this pack: mail, files, chat, meetings, and business process. Microsoft Graph is its API and data plane. Conceptual 100 no Microsoft Graph, Software-delivery platform Conceptual view [S10]
Entra ID Microsoft's identity service for this pack. Users and apps authenticate here. Physical 100 yes Conditional Access, Workload identity Physical view, cheatsheet [S18]
Event-driven integration A source publishes a webhook or event; a consumer reacts. Used when systems must respond to a change instead of polling. Logical 200 no Graph change notifications Mind map, logical view [S20]
externalItem The Graph object a synced connector writes. It carries content, properties, and an ACL. Logical 200 yes ACL, Synced connector Study guide, physical view [S15]
Federated connector Live fetch at question time through MCP. Content is not copied into Microsoft Graph. Use it when data is volatile, sensitive, large, or when a write must hit the source. Logical 200 yes Synced connector, MCP Blocks, logical view [S4] [S3]
GitHub App Server-to-server GitHub integration with fine-grained permissions and short-lived installation tokens. Preferred over a broad OAuth app or a PAT. Physical 200 yes PAT, Checks API Mind map, integration risks [S16]
GitHub Cloud Knowledge connector Microsoft connector that indexes selected GitHub Markdown and docs into Graph so Microsoft 365 Copilot can ground on them. Integration & AI 200 no Synced connector, GitHub Copilot Source ledger, logical view [S5]
GitHub Copilot The coding assistant (IDE, CLI, chat, coding agent). Licensed separately from Microsoft 365 Copilot. Platform 100 yes Microsoft 365 Copilot, MCP Cheatsheet, mind map [S12]
GitHub Copilot Extensions Older GitHub App model for extending Copilot. GitHub documents MCP as the current extensibility path. Integration & AI 200 no MCP server, GitHub App Mind map, study guide [S7]
Graph change notifications Webhooks from Microsoft Graph when a resource changes. The subscriber then reads the authorized change. Physical 200 no Event-driven integration, Microsoft Graph Mind map [S20]
Graph Data Connect Bulk, governed export of Microsoft 365 data into an Azure analytics store. Not the same as a Copilot connector. Platform 200 no Microsoft Graph, Copilot connector Mind map [S21]
Indexed knowledge connector Same idea as a synced connector: copy external content into a Graph external connection so Search and Copilot can retrieve it. Logical 200 no Synced connector, externalItem Mind map, study guide [S3] [S15]
Knowledge plane Curated information made searchable through synced connectors and the Graph index. A name this pack uses, not a Microsoft product name. Conceptual 200 no Synced connector, Transaction plane Conceptual view UNVERIFIED
MCP Model Context Protocol. A way for a host (Copilot) to call tools and read context from an external server. GitHub's primary Copilot extensibility path, and the wire for federated connectors. Integration & AI 100 yes MCP server, Federated connector Blocks, all views [S6] [S4]
MCP server A process that exposes tools to Copilot. Catalog it. Split read-only tools from write tools. Integration & AI 200 no MCP, Prompt injection Conceptual view, integration risks [S7]
Microsoft 365 Copilot The work assistant over mail, files, meetings, and Graph. Not the same product as GitHub Copilot. Platform 100 yes GitHub Copilot, Microsoft Graph Cheatsheet, source ledger [S10]
Microsoft Graph The permission-aware API and data plane for Microsoft 365 content and for Copilot APIs. Platform 100 yes Copilot APIs, externalItem Mind map, conceptual view [S1] [S15]
OAuth 2.0 Delegated or app authorization. Graph and GitHub both use it. Broad scopes are a risk on GitHub; prefer a GitHub App for service-to-service. Physical 200 no GitHub App, OIDC Physical view [S16]
OIDC OpenID Connect. Identity layer on OAuth, used for sign-in. This pack does not yet cite an Entra protocol page for it. Physical 200 no OAuth 2.0, SAML Physical view UNVERIFIED
PAT Personal access token. A user secret with a lifetime you set. Avoid it for a service; use a GitHub App installation token. Physical 300 yes GitHub App Study guide [S24] [S16]
Permission fidelity Source-system rights must survive the trip into Graph ACLs. If the mapping is wrong, Copilot retrieval spreads the mistake. Integration & AI 300 yes ACL, externalItem Integration view [S15] [S3]
Power Platform connector Low-code connector used by Power Automate and Power Apps. Different surface from a Copilot connector. Platform 200 no Copilot connector, Dataverse Mind map UNVERIFIED
Prompt injection Hostile text inside retrieved content that tries to override the model's instructions. Treat retrieved text as data; gate actions outside the model. Integration & AI 300 yes MCP server, Permission fidelity Integration view UNVERIFIED
SAML Older SSO federation option, an alternative to OIDC. This pack does not yet cite an Entra SSO page for it. Physical 200 no OIDC, Entra ID Physical view UNVERIFIED
SCIM Protocol Entra app provisioning uses to create, update, and disable accounts in a target app. Physical 200 no Entra ID, Workload identity Physical view, study guide [S23]
Semantic index Microsoft's index that Copilot uses for grounding. Synced connector items land where this retrieval can see them. Logical 200 yes Synced connector, Microsoft 365 Copilot Study guide [S11] [S3]
Software-delivery platform The GitHub side of this pack: repos, review, Actions, packages, release. Conceptual 100 no GitHub Copilot, Digital-work platform Conceptual view [S12]
Synced connector Pulls external content on a schedule into a Graph external connection, including content, properties, and an ACL. Good for search; a poor place for secrets and fast-changing records. Logical 200 yes Federated connector, externalItem Blocks, logical view [S3] [S2]
System of record The one authoritative store for a fact. Copilot must not become a second one. Conceptual 100 yes Synced connector, API consumption Conceptual view UNVERIFIED
Transaction plane APIs and workflows that change state. Distinct from the knowledge plane. A name this pack uses. Conceptual 200 no Knowledge plane, API consumption Conceptual view UNVERIFIED
Work IQ API Microsoft extensibility API named in the Copilot extensibility overview as part of how Copilot reasons over work context. Platform 200 no Microsoft 365 Copilot, Copilot APIs Study guide, source ledger [S9]
Workload identity An app or service identity, not a person. Server-to-server calls should use this, or a GitHub App, not a shared user account. Physical 300 yes Entra ID, GitHub App Study guide [S18] [S16]

Grounding Copilot prepares a prompt with Microsoft Graph data the signed-in user can already open, then sends that grounded prompt to the model. Data protection 200 yes Microsoft 365 Copilot, Microsoft Graph Integration view nblm-gap [S11] [S4]
Permission trimming Copilot returns only what the signed-in user is allowed to open. It does not get tenant-wide visibility. Data protection 200 yes ACL, Grounding Integration view nblm-gap [S11]
LLM The model that writes the Copilot response from the grounded prompt. It is not the system of record for mail or files. Delivery 100 no Grounding Integration view nblm-gap [S11]
SharePoint A Microsoft 365 store for files. Copilot reaches the files the user can open. Restricted SharePoint Search can narrow that set further. Neighbor system 100 no Microsoft Graph, Grounding Integration view nblm-gap [S11]
Oversharing Copilot retrieves an item the user could not open in the source system, usually because the synced ACL is wider than the source rights. Data protection 300 yes ACL, Permission fidelity Integration view nblm-gap [S15] [S3]
Webhook A callback Microsoft Graph can send when a resource changes. The subscriber then reads the change instead of polling. Integration 200 no Graph change notifications Logical view nblm-gap [S20]
REST The HTTP style of the Copilot APIs on Microsoft Graph. Integration 200 no Copilot APIs Physical view nblm-gap [S1]
GraphQL GitHub's query API. One request can read a repository together with related objects such as pull requests. Integration 200 no GitHub Copilot Physical view nblm-gap [S26]
GCC Office 365 Government Community Cloud. Customer content is stored in the United States and kept logically separate from commercial Office 365. Government cloud 200 no GCC High Physical view nblm-gap [S27]
GCC High Office 365 government environment for DoD security requirements, DFARS, and ITAR. It is not the Department of Defense tenant. Government cloud 200 yes GCC, DoD Physical view nblm-gap [S27]
DoD The Office 365 environment for the United States Department of Defense only. Government cloud 200 no GCC High Physical view nblm-gap [S27]
