Standards and protocols (StdV-1)

Standard / protocol Used for Required or optional
OAuth 2.0 / OIDC Federated user identity, service-to-service auth, MCP connector auth Required
SAML SSO federation into Entra ID Optional (alternative to OIDC for SSO)
SCIM Automated joiner-mover-leaver identity lifecycle Recommended
Model Context Protocol (MCP) Federated connector live data fetch; GitHub Copilot tool/context access Required for federated connectors and GitHub MCP integration
Microsoft Graph externalItem schema Defines synced connector content/metadata/ACL structure Required for synced connectors
REST Microsoft Graph API, GitHub REST API, Copilot APIs Required
GraphQL GitHub GraphQL API for relationship-rich queries Optional (alternative to REST)
Webhooks (HTTP callback) GitHub event delivery, Graph change notifications Required for event-driven patterns
