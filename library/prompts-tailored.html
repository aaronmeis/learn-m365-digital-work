Tailored prompts — Microsoft's Digital-Work Platform

Read by w8-prepare (T1-T4). Edit freely; keep the ### Tn headings.

T1

Using only the sources, write the CONCEPTUAL architecture view of Microsoft's Digital-Work Platform. Cover the problem it solves, the actors and their goals, the capabilities it provides, and the key concepts and how they relate. Do not name products, SKUs, services, or regions; this is the capability altitude. End with a table mapping each capability to the source that supports it. Mark where the sources are silent.

T2

Using only the sources, write the LOGICAL architecture view of Microsoft's Digital-Work Platform. List the logical components with their responsibilities, inputs, and outputs; the logical data entities with key attributes and relationships; and the main flows between components (trigger, payload, sync or async). Stay vendor-neutral where the sources allow. Mark silence.

T3

Using only the sources, write the PHYSICAL architecture view of Microsoft's Digital-Work Platform. Map each logical component to the named service or feature that realizes it, where it runs, the agents or connectors deployed on-premises, licensing tiers, data stores and residency, and the differences across commercial, GCC, GCC High, and DoD or government-secret clouds. Mark silence, especially on government-cloud availability.

T4

Using only the sources, describe the AI elements of Microsoft's Digital-Work Platform: each AI or copilot feature, the data it reads and writes, the grounding path, the controls that govern it (labels, DLP, access, audit), and how AI interactions are logged and retained. Then list the integration surface: APIs, SDKs, connector frameworks, and identity. Mark silence.
