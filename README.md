# Learn Microsoft's Digital-Work Platform

Study console for the Microsoft 365 and GitHub digital-work architecture pack: conceptual, logical, and physical views, synced versus federated connectors, the AI data path, and a daily architecture challenge. Same no-build pattern as [learn-purview](https://github.com/aaronmeis/learn-purview).

**Live:** https://aaronmeis.github.io/learn-m365-digital-work/

**Today** is the daily challenge (question of the day from the deep-dive cut, a failure-mode drill, and a placement drill), with a streak and goal rings. **Learn** is the 8-block day. **Practice** is the glossary, quiz, and failure modes.

The Obsidian pack at `Learning/tech-deep-dive/m365-digital-work-platform/` is the source of truth.

```
python scripts/stage_assets.py
python scripts/build_library.py
python scripts/build_console_data.py
```

Saved progress uses the `lm365dw:` prefix so it does not collide with the other study sites on this GitHub Pages origin.

The scope mind map is `assets/diagrams/00-mindmap.png`, drawn from the vault intake note. The deep-dive cut and shorts 01-09 play from unlisted YouTube videos. Shorts 10-16 play from MP4s in the repo until the YouTube upload quota resets. IDs live in `scripts/stage_assets.py`.
